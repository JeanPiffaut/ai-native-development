# entorno/

Conocimiento del entorno que comparten los proyectos. Un archivo por tema.

- `<tema>.example.md` (en git): qué se anota y con qué forma, con valores **inventados**.
- `<tema>.md` (local, ignorado por git): los datos reales. Se crea copiando el ejemplo.

Cada archivo real empieza con `Última revisión: AAAA-MM-DD` y cita de dónde sale cada dato (consola, repo, decisión de un proyecto). Sin secretos ni datos de clientes: los secretos van en el gestor de secretos del ambiente; aquí solo su nombre.
