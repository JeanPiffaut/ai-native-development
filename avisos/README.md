# avisos/

Buzón entre proyectos. Un archivo por aviso: `AAAA-MM-DD-<origen>-a-<destino>-<tema>.md`, con el formato de `EJEMPLO.md`.

- Lo crea la sesión del proyecto que encontró algo que sirve o afecta a otro.
- Lo atiende la sesión del proyecto de destino: lo lista en `/iniciar`, lo trabaja en su propio board y lo pasa a `estado: hecho` con una línea de resultado.
- Destinos posibles: el nombre de un proyecto, `plantilla` (framework genérico) o `todos`.
- Los avisos reales no se versionan (ignorados por git).
